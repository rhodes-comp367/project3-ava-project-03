# Final project

**Explain the general theme and specific features of your project.**
The goal of my project was to create a circular linked list. I started by setting up a singly linked list and then
I created a function called next to give the full list and the current list (if it is at the end of the list, it circles back and gives
the full list).

**Cite any resources or existing code you used.**
I avoided using the standard library or any other previously created circular linked lists for code. I used ChatGPT to help me come up with the ideas for the proof.


**Discuss any challenges, or anything you'd like feedback on.**
I am not sure my project is correctly set up. If I were to do this project again, I would have used the concept of Nodes, like how I have previously used them in other programming classes, and adapted that to fit Agda instead of using full and current. I struggled to come up with the basic foundation for this project, and I think I would have been able to do a lot more if I had a better grasp of that.
